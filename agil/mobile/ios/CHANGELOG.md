# Changelog

## 0.1.0 (unreleased)

Initial SwiftPM iOS module (`AgilCallsSDK`) for the hosted `/embed.html` widget.

### Security

- `allowedOrigins` now rejects plain `http://` origins unless they are loopback
  or `allowsInsecureHTTP` is explicitly enabled (aligned with the Android SDK).
  The navigation guard applies the same rule.
- Native bridge messages are accepted only from the widget origin's main frame
  (`frameInfo.securityOrigin`) and must carry the per-load nonce envelope
  generated by the injected shim. `allowedOrigins` only expands navigation.
- Token redaction covers camelCase keys (`joinToken`, `apiKey`, ...), optional
  whitespace around `=`, and percent-encoded assignments (`token%3D...`).

### Fixed

- Chat messages forwarded by `embed.html` (`from: { id, name }`) now populate
  `AgilChatMessage.participantId`/`participantName`; the flat fields still win
  when present and `raw` keeps the original object.
- `language` accepts BCP-47 input but normalizes to the supported `ru`/`en`
  values instead of silently passing unsupported locales to the widget.
- Example XcodeGen spec points at the package root (`path: ..`).
- Added `pip`/`newtab` actions and the `requestPictureInPicture()`/
  `openInNewTab()` helpers; `join` is documented as not supported by the hosted
  page.
- Added OIDC `identity_not_verified`/`identity_not_configured` client errors and
  HTTP-date `Retry-After` parsing.
- `widgetPath` rejects a trailing slash; `serverURL` lowercases the host and
  rejects dot segments; `AgilJSONValue.intValue` no longer truncates fractions.
- Documentation now states that `identity_token` is in the page URL per
  `agil/core/docs/contract.md` §7, plus the iOS 14.x media-capture, Linux test
  reproduction and Android cross-reference notes.

### Known limitations

- No native WebRTC, CallKit, PushKit, background audio or screen share; media,
  chat and theming stay in the hosted widget.
- The package has not been compiled with an Apple SDK on this host; run the
  macOS `xcodebuild test` gate before publishing.
- No `LICENSE` file in the monorepo yet; add one before standalone distribution.
